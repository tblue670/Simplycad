PRIMA PUBBLICAZIONE (una volta sola, da Chromebook o PC, con Chrome)
 1. Crea l'account gratuito su https://github.com (conferma l'email).
 2. In alto a destra "+" -> "New repository".
      Repository name: simplycad      Visibilità: Public (obbligatoria per il sito gratuito)
      Lascia vuoto il resto -> "Create repository".
 3. Nella pagina che compare tocca il link "uploading an existing file".
 4. Estrai lo ZIP, apri la cartella "simplycad", seleziona TUTTI i file al suo interno
    e trascinali nel riquadro (non trascinare la cartella: i file devono stare "in cima").
    In basso -> "Commit changes".
 5. Nel repository: "Settings" -> a sinistra "Pages" -> Source: "Deploy from a branch",
    Branch: "main", cartella "/ (root)" -> "Save".
 6. Dopo 1-2 minuti, in cima alla stessa pagina compare l'indirizzo:
      https://<tuo-nome-utente>.github.io/simplycad/
    (ricarica la pagina se non lo vedi ancora).

INSTALLARE L'APP
 - Android: apri l'indirizzo con Chrome -> tre puntini -> "Installa app".
 - Chromebook / PC: icona di installazione nella barra degli indirizzi (o menu File -> "Installa app").

AGGIORNARE A UNA VERSIONE NUOVA
 1. Nel repository -> "Add file" -> "Upload files".
 2. Trascina i file della nuova cartella (stessi nomi: sostituiscono i vecchi) -> "Commit changes".
 3. Aspetta 1-2 minuti che GitHub pubblichi (in "Actions" il pallino diventa verde).
 4. Alla successiva apertura l'app chiede "È pronta una versione nuova: aggiornare?" -> conferma.
    Se non lo chiede, chiudi e riapri l'app.
